## 🎯 About The Project

**SKLP Car Rental** is a web-based platform built to simplify the car rental process for both customers and administrators. During my internship at SKLP Car Rental, I conceptualized and developed the full-stack platform from scratch—handling everything from database schema design and backend configuration to building responsive, user-friendly frontend interfaces.

The goal of the project was to digitize rental tracking, vehicle availability checks, and reservation management to improve operational efficiency.

---

## ✨ Key Features

- **Vehicle Catalog & Filtering:** Browse available cars with details on pricing, specifications, and status.
- **Rental Booking System:** Seamless reservation workflow allowing users to select pickup/drop-off dates and book vehicles.
- **User Authentication & Profiles:** Secure user registration, login management, and booking history tracking.
- **Admin Dashboard:** Administrative controls for managing vehicle inventory, updating rental statuses, and monitoring bookings.
- **Responsive UI:** Clean, mobile-friendly interface designed for optimal accessibility across devices.
